# A place for everything.

Welcome to Lambda Finder, a native file browser inspired by macOS.

Double-click a folder to explore. Select a document to see its preview,
or press Space for Quick Look. Switch between icon and list views in the
toolbar. Search filters names in the current folder.

The sidebar opens real folders on your computer. Go to Folder accepts an
absolute path, a relative path, or a path beginning with ~/.

This demo browses and previews files without changing them.
