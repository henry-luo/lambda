# Greetings music

Five original instrumental miniatures synthesized for this demo. They contain no
recordings, samples or third-party compositions and use the repository's license.

Regenerate the 16 kHz, 16-bit mono WAVs with:

```sh
python3 test/demo/greetings/_generate_music.py
```

`celebrate` and `sunshine` run for 12 seconds, `winter` and `affection` for 16,
and `lullaby` for 20. A rest at the end leaves room for a gentle repeat.
