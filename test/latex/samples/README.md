These are source samples for compatibility work, not expected-output tests.
The selected source files contain no references to separate image or input
files. They can still require installed LaTeX packages, fonts, or a specific
engine such as XeLaTeX. The retained `arithmetic_lualatex.tex` is a negative
compatibility example: embedded Lua is outside Lambda's LaTeX support.
`biblatex_biber.tex` creates its bibliography data inline with `filecontents`;
processing it with standard LaTeX still requires Biber.
