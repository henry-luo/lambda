# Authored EPUB fixtures

All 14 EPUB files are original test data generated by `generate.py`; no books
or assets were downloaded. The minimal fixture includes Lambda-authored text,
a red-dot SVG, local CSS, relocated OPF, Unicode, nested EPUB 3 contents,
landmarks and publisher page links. ZIP timestamps and member order are fixed.
Regenerate with `python3 test/input/ebook/generate.py`.

| Fixture | Coverage |
|---|---|
| minimal | EPUB 3, two chapters, local CSS/image, cover and navigation |
| epub2 | EPUB 2 OPF and NCX |
| paged | 60 paragraphs spanning generated column pages |
| fixed | XHTML pages with a 600 × 800 source viewport |
| svg | SVG spine document and source dimensions |
| encoded-links | Percent-escaped fragment IDs and passage positioning |
| fallback | Unsupported spine media falling back to XHTML |
| css-import / css-cycle | Relative imports/resources and cycle rejection |
| missing-spine / escape / protected | Missing ID, package traversal and encrypted required text |
| unsafe / raw-style | Active elements, external resources and CSS raw-text boundaries |

Functional goldens live in `test/lambda/ebook/`. Native UI fixtures cover the
reader, paginated and fixed layouts, file-browser preview, and generic iframe
navigation delegation. They are discovered by the baseline UI manifest.
`test/epub_reader_check.py` checks persisted preferences/bookmarks, moved-file
resume and rejection of an altered saved passage, and is registered in the
Radiant baseline through `test/run_epub_reader.js`.

These small fixtures establish the declared initial profile. They do not
establish full EPUB conformance, RTL/vertical writing, CFI, obfuscated fonts,
complex paged CSS, or fidelity against an independent reading system.
