# Profiled screenshot fixture

`profiled.png` is a synthetic 128 × 96 RGBA PNG filled with `(220, 40, 60, 128)`.
Its iCCP chunk contains an sRGB profile generated by Pillow/LittleCMS; the profile
timestamp is fixed to 2020-01-01 for repeatability. It contains no user screenshot
data. The embedded profile reproduces Preview/screenshot paste being rejected by
the sRGB-only image compositor. The matching pure golden embeds these same bytes
so it needs no filesystem effects (S12.1.3).
