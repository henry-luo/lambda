# Package-stage fixture

Authority: **D7.5.2, D7.5.8**. `package.zip` is an inert deterministic public
archive generated by `python3 test/safety/generate_stage_fixture.py`. Its files
are script text, a short message and an empty file; no private keys or installed
package state are included. The paired `safety_package_stage.ls/.txt` golden
checks portable names, namespace rejection, captured bytes, empty members,
executable intent and terminal-state refusal on interpreter, JIT and auto tiers.

`python3 -O test/safety/test_package_stage.py` builds and pins the immutable
runtime, stages an explicitly unhardened ad-hoc fixture bundle under `temp/`,
and exercises the actual early-confined offline interpreter. Run this with
native macOS process-policy access; an enclosing agent sandbox prevents the
private Darwin policy from being installed and is not a successful test.
`--no-build` uses already built executables. It never installs signing identities,
uses user settings, fetches remote data, publishes package files or activates an
image. All assertions remain active with Python optimization enabled.

The 53 cases cover exact stored/deflated bytes, implicit directories, zero-byte
files and empty archives; literal percent/space names; the 16 MiB member, 64 MiB
expansion and 4,096-entry boundaries; traversal/absolute/drive/stream/device and
reserved names, Unicode-profile refusal, case collisions and type conflicts;
links/special files, setuid/sticky modes, oversized entries/expansion/counts,
truncation/encryption/CRC corruption; initial-frame rejection before allocation,
denied/nonempty/replayed acknowledgements and channel closure. A late CRC
failure never sends completion. Package script bytes remain inert, demonstrated
by a preserved fixture canary.

This qualifies the decoder/IPC component on this Mac, including failures with
exit 3 rather than crashes or startup failures. It does not qualify hardened
publisher launch, managed-image publication, activation or the complete app
boundary. The separate [protected staging fixture](../test_update_stage.py)
now exercises the host adapter and bounded identity-bound cleanup, including
three signed HTTPS/TUF cases. Its first ten mechanism cases use the explicitly
test-only artifact factory; production accepts opaque verifier artifacts only.
See the [component contract](../../../lmd/package/security/Stage.md).
