Pages in Radiant

This document uses CSS paper size, page margins, running headers and page counters.

Scroll with the mouse wheel or arrow keys. PageUp and PageDown move through the preview; Home and End jump to its ends.

A reusable print layout

The same composed pages can be viewed here or exported to PDF, SVG and PNG. Window resizing changes the visible area while the paper dimensions stay fixed.

Try a two-column preview with --page-grid 1x2 --page-column-gap 24, or a facing spread with --book --book-page 2.
