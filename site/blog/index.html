Lambda Script 0.3 Alpha

October 2026

Lambda Script 0.3 is the first alpha release since 0.2 in March. Highlights:

  • Faster JIT. MIR Direct is now the only back end. Across 63 benchmarks, typed Lambda code runs 1.8× faster than Node.js V8 by geomean (0.54×), and untyped code is roughly on par (1.05×).
  • Document editing. lambda edit opens Markdown, HTML, and SVG documents in an editor and saves them back to the file.
  • Reactive UI. view/edit templates, apply(), and event handlers for building interactive apps in Lambda.
  • Concurrency. Tasks, mailboxes, select, timeouts, and cancellation.
  • String patterns. A pattern language inside \(…), used by find, replace, and split.
  • More diagrams. Structurizr C4 workspaces and TikZ/PGF pictures join Mermaid, D2, and GraphViz in render and view.
  • JavaScript engine. The experimental LambdaJS engine passes 40,261 test262 tests with 0 failures.
  • Standards. CommonMark 655/655, YAML 1.2 276/276, and html5lib tree construction 364/364.

There is also a new ten-chapter tutorial, from installation to a reactive app. This is an alpha: expect rough edges, and please report issues.

Why Lambda Script: Documents as Data

April 2026

Lambda Script approaches documents differently. Instead of treating formats as output targets, Lambda parses 20+ input formats into a unified Lambda/Mark node tree. This means your Markdown, HTML, JSON, YAML, LaTeX, or CSV files become structured data you can query, transform, validate, and render — all with one language and one runtime.

Where most workflows require stitching together pandoc, jq, custom scripts, and template engines, Lambda provides a single, coherent pipeline:

// Parse any format → unified tree → transform → output
let doc = input("report.md", 'markdown')^
let images = [*doc?<img>] |> ~.src
let headings = doc?(<h1> | <h2>)

// Build a styled HTML page with a table of contents
let page = <html
  <head <title "Report">>
  <body
    <nav <ul for (h in headings) <li h[0]>>>
    for (block in content(doc?<body>)) block
  >
>
format(page, 'html')

Combined with JIT-compiled performance (competitive with V8, 13× faster than CPython), a rich type system, and a built-in HTML/CSS/SVG layout engine, Lambda Script is designed for anyone who processes documents or structured data as part of their workflow.
