## Evidence and changes

The baseline source has `radiant` linked to `lambda-rt`, mixed `lambda-data`/Radiant source ownership, and native-looking test files that import runtime and JS. A directory move alone cannot establish D9.1.1v4. See the design appendix for the source pointers.

The lifecycle seam preserves refusal and retry: runtime preflight happens before destructive cleanup, and a failed host release retains the document and runtime. The provider table is immutable and registered once; missing or incomplete tables never pretend that a live document was retired. It shares the atomic provider-registration helper with the DOM seams rather than introducing a second registration algorithm (D9.1.3v2, D5.5.2, D6.3.3).
