# Concrete path access and escaped path references

**Status** — Local filesystem behavior and named context roots are implemented on the host, 2026-11-18. Non-host qualification and the GC static-audit failures remain open.

**Authority** — S2.4.1v3–S2.4.8, S7.1.1v3, S8.2.1v5, S10.1.2v5, S10.1.6v2, S10.6.1v3, S16.9.4v2, S17.3.1v2 and D10.1.8. [Path semantics](../../doc/Lambda_Formal_Semantics.md#s24-paths) · [Source form mapping](../Lambda_Expr_Path.md)

## Current checkpoint

- Branch `master`. Bare provider access and captured references now share the force walker. Interpreter and MIR both lower ordinary brackets on concrete nodes and capture brackets on references.
- S2.4.5v6 maps `file./.path` to `file:///path`. That alias and `file.localhost.path` select the same node and capture the same address. The printer preserves the authority spelling from the source.
- The existing `\./` step keeps its receiver-relative root meaning. Use `\.file.localhost.path` to capture an explicit local absolute address. A spelling for capturing the evaluation's logical `/` independently of its provider remains open.
- File nodes get their kind from metadata and hold the parsed document after its first field or content read. Virtual node display shows the tag without opening children. SO31 still tracks the full file metadata shape.
- `make build` passed. The syntax harnesses passed 470 production-parser cases and 457 reference-grammar cases. The focused golden run passed 49 cases covering paths, references, navigation, and update scopes.
- The relative and absolute path probes passed with forced GC on interpreter, MIR and auto. Eight scoped native tests passed on interpreter and MIR, including zero payload reads for `is file`, a read on first content demand and denial after authority revocation.
- The migration replaces obsolete `#` on concrete `sys` accesses and migrates address-consuming fixtures to the escape. All 319 scripts in the changed-source compile sweep type-checked. The earlier full script sweep started before those migrations and encountered timeouts in document fixtures. Full qualification requires a clean sweep of the final sources.

## 6. Named context roots (`~word`)

**Status** — Implemented and tested on the host under S2.4.8, S10.1.2v5, S10.1.6v2 and S17.3.1v2. Windows and WASM remain unqualified. [Working design](../Lambda_Expr_Path.md#named-context-roots)

**Implementation audit** — The production lexer currently emits the unknown-accessor token for every fused word except `~key`, and the parser rejects it. The escaped path parser has a separate segment path that also needs a context-root form. `EvalContext.current_file` is for diagnostics, so it cannot by itself provide the defining file of a function imported from another module. The `sysinfo` resolver already exposes `proc`, `home` and `temp` and should be reused when connecting context roots. These findings do not yet change runtime behavior.

**Checkpoint** — The `sys.proc.self` map now includes `argv` and `env`, using the same resolver as direct paths. `make build` passed, and a focused script confirmed bound `pid`, `cwd`, `argv`, and `env.PATH` agree with direct access. The context-word syntax, root representation, ownership, and both execution tiers remain to be implemented and qualified (S2.4.8, S17.3.1v2).

**Checkpoint update** — `~proc` and `\.~proc` lower to the existing `sys.proc.self` address, so they use the ordinary resolver on both tiers. `test/lambda/path_context_proc.ls` checks bound and direct members and reference composition. Forced-GC probes passed on interpreter, JIT and auto. `make build` and `make test-grammar-s16` passed. The remaining six context roots and their capture and ownership contracts are open.

**Directory roots** — `~cwd`, `~home`, and `~temp` now construct local file addresses through a shared runtime entry point and use the existing lazy force walker. `test/lambda/path_context_dirs.ls` covers capture, composition and file-kind access on interpreter, JIT and auto with forced GC. `make build` passed. Evaluation-lifetime snapshots, unavailable directories, platform-specific path cases, the user/document/script roots and broader qualification remain open (S2.4.8, S2.4.4v2).

**Script root** — `~script` captures its defining script's source at AST construction. `test/lambda/path_context_script.ls` and `mod_context_script.ls` check local and imported file references on interpreter, JIT and auto with forced GC.
